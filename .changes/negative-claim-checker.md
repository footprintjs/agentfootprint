**The negative-claim checker, pure and not yet wired.** `src/integrity/negative-claim/` checks "there are none", "not found" and "the list is complete" against what a search was made of, by code only. A typed claim cites the library-minted result identities of the reads it rests on and is established only from those reads, with a library-written statement that attributes every text to the tool, the model or the result and lists every gap; a prose claim found by a fixed, versioned and hashed grammar is only noted. `bench/negative/` replays the grammar over recorded replies for free; on its first run the prose grammar failed every gate it could be read on, and the typed path is unmeasured. Nothing in a run changes: no agent calls the checker yet.

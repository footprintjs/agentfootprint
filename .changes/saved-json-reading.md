**Open saved JSON tool results through opt-in conversation admission.** `artifacts.reading` mounts the existing bounded detail viewer and eligible placement tickets carry an issued detail action. `sessionArtifactAdmission` repeats scoped metadata and payload checks on every request, with exact allowed kinds, byte limits and an optional narrowing host check. Declared JSON text is decoded once for viewing; stored bytes and existing defaults stay unchanged. Reading adds no producer, current-run or claim authority, and fixed refusals preserve the host's downstream output limits.

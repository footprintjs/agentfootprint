**`agentfootprint/time` — the time layer's own period conversion, for an app outside a run.** An app that previews what a tool would read for the person's window, or builds a call itself, used to keep its own copy of the conversion, and a copy drifts the first time the fill's rules change. Three pure functions now ship on a new door: `convertExact` returns the first declared form that holds a window exactly, as the argument values to send. `convertWidened` returns the first form that reads more (a whole day, or the covering look-back from now), with the range the tool reads (`sent`) and what it adds (`extra`). `periodFactProblem` returns which declared fact (`direction`, `retention`, `maxRange`) a range breaks. Their types ship with them: `ConvertContext`, `WindowToConvert`, `Conversion`, `WidenedConversion` and `PeriodFactProblem`. They are the same function objects the fill calls, so a preview shows what the run sends. They need no run, write no record and do not need `.time()`. They live on their own door because they are part of the layer's run-time half: the main barrel still keeps that half off a plain agent's import graph, and nothing a plain agent loads changes.

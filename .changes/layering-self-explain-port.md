**The agent builder no longer imports the trace toolpack.** `.selfExplain()` now reaches it through a port in the agent (`core/agent/selfExplainPort.ts`); the toolpack registers its three pieces there at load (`lib/trace-toolpack/selfExplainHost.ts`), and the published doors take `Agent` and `AgentBuilder` from that module, so the registration travels with the class — also through a bundler that skips a barrel (the module is listed in package.json `sideEffects`; webpack and rolldown both drop a registration placed in a side-effect-free barrel). The method, its options and its behaviour are unchanged, every door exports the same names, and only an internal module path, which package.json `exports` does not resolve, could reach `build()` unregistered. The last upward import left the layer table's allowance list, which is now empty (`npm run check:layering`).

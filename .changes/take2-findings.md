**A duration the person's own window implies is derived, not invented; a resumed answer's account reads the part before the pause from its record.**

The time layer's one owner of "which spelling of a time is whose" (`core/time/forms.ts` · `timeFormsOf`) now spells a recorded window's length in the library's `derived` lineage — as said ("6:25 to 6:45 AM" is `20-minute`, `20min`, `1200s`, `0.33h`, `PT20M` …) and as read to the end of its grain (`[06:25, 06:46)` is `21-minute`). The evidence gate already asks that list before it flags a value, so an answer that says "that 20-minute window" for the person's confirmed window is filed `time-derived` ("not sure", never "known") instead of "a value no tool returned". A length the window does not have (`45-minute`) is still flagged. Only whole-token spellings are listed, so a bare count such as `20` never grounds a figure. The same owner now also spells, as `derived`, the turn's clock at the minute it is served on every request ("This turn's time: …" — `7:08`, `7:08am`, the date, the year; never another minute or the clock's seconds) and every reading the time ask OFFERS that the person has not answered yet (`06:25:00` for "6:25", the implied year) — so a model that repeats the time it was told, or restates the reading it is waiting on, is no longer flagged as inventing it.

"Explain this answer" (`accountForAnswer`) on a resumed leg no longer says "what happened before the pause is not in this record" when the record holds it. A resumed leg's recording carries the state the run paused with (`snapshot.initialState`) and the committed state after it, so each call answered before the pause is now listed in "It checked", "It did not check" and "It found" — what came back (history) and what its tool declared (`coverageDeclared`) — and the existence and empty-result checks judge those calls too. What is not recoverable is said exactly: that part's events (the routing verdict, what was in front of the model then, whether a call then failed or was refused). The one-liner is the one any answer gets, followed by that. A recording without the paused state keeps the old "not in this record" sentences — the one case they are true. Template set version 8; `facts.beforePause` entries gain `emptiness`, `rows`, `coverage` and `pointers`; "show me" shows the tools' own words on `coverageDeclared` rows.

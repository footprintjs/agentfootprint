type: breaking

Runs now use footprintjs's native lifecycle. Independently mounted components keep separate private state, and cleanup and typed-answer processing remain inside the owning run.

Migration: await each operation before starting another on the same runner. Use separate instances for independent conversations. `RunInFlightError` is the native class: match `ERR_RUN_IN_FLIGHT`; `runnerId` replaces `agentId`, and `activeRunId` can be absent. Its message no longer includes recovery advice. Read run IDs from execution events; `makeRunId` is removed.

Migration: recreate saved pauses with this version. They now retain explicit caller/session origins, finite resource references and the declared tool parties the model saw. Agent resume must keep the paused identity and transport session; its supplied `sessionId` must match. Composition resume does not enforce this Agent-specific transport check. Hosted questions with an unreadable carrier are closed with a notice, so the next message can continue. Missing or inconsistent data refuses before tool effects. Provider IDs are cooperative labels, not authentication. Continue protecting checkpoints at the host boundary.

Migration: retain and answer the returned pause. On a fresh instance, a partial typed answer that has not reached native execution has no local pending-question guard; its checkpoint still holds the question. Hosted agents keep that question in their session store. During a new call's preparation, snapshot and conversation readers return `undefined`, commit counts are zero and narrative entries are empty. Capture prior records before starting the call. After a leg starts, readers follow it even if it fails; shared-instance readers are not per person, so use one instance per conversation. Missing-answer refusals, synchronous membership reads of this process's issued in-memory ledgers, and witnessed local close facts can refuse before origin on consent resumes. Opaque ledger implementations reach the atomic spend inside execution; optional reads cannot establish a preflight replay fact, authorize a call, or discard its question. Their refusals and spend races may therefore occur after origin. After a failed spend, an optional `isSpent` observation uses a fixed 100 ms timeout and can stop earlier on cancellation. A missing, failed, non-boolean, late or timed-out observation stays unknown and is treated as possibly used; a later `false` does not revise that conservative outcome. Actual local close receipts retain at most 1,024 exact ledger/request pairs; eviction or a process restart loses that local evidence, and an opaque ledger's optional positive read cannot recreate proof that a call did not run. `followUp` validates identity shape first and refuses a conflict with an explicitly named prior caller, while an anonymous conversation may acquire a named caller.

Migration: custom `RunnerBase` subclasses must supply `initChart`'s execution configuration and initializer, execute through `runExecution().withRun`, use the invocation's view and `execute`, pass that invocation to `detectPause`, and call `noteResumeTakenUp` before resume admission. `lastExecutor` and `openRunRedaction` are gone; use `prepareRunRedaction` and native setup. The corresponding `RunnerInvocation`, `RunnerSelection`, `RunnerMetadata` and `RunnerCoreValues` types are exported. Old subclasses must be rebuilt.

Migration: `session` resource registrations are partitioned by tenant/principal/session and reuse `(tool, scope, key)` within that partition. `shutdown` registrations reuse `(tool, scope, key)` across conversations in the tier. They do not restart an interpreter each turn. `call` and `run` resources use native turn/call ownership, with exclusive borrowing on resume. Pauses retain resources; accepted answers join cleanup. Refused answers restore only a previously held local question; a host store owns transferred questions. A local reference is not a live handle or proof of remote closure. The `agentfootprint.tools.resource_restore` event reports `retained`, `none-known-locally` or `unconfirmed` for the restored owner's local state; an unrelated tier-wide shutdown row is not evidence for that owner. Remote state stays `unknown`. Use explicit host abandon, close or shutdown controls when discarding a stored question.

Migration: causal memory readers require `schemaVersion: 2` and skip/count older or invalid rows. Evidence covers one component leg, with explicit availability and omissions. Custom evidence callbacks must use their supplied native parent binding, not another run's selected snapshot. Resume creates new observation handles without resetting conversation budgets.

Migration: use `swarm({ agents, router })` instead of separately sequencing `router.route` and `router.step`; the old step chain can pass an empty message. Native event run IDs replace separately minted domain IDs. Log IDs and resume-leg IDs can differ. Records commit `toolResourceOwner`, `runIdentitySource` and `runSessionId`; the final stage narrates their `Input:` entries. Resource binding can add `toolResourceOwner` read keys and `Read`/`Write` entries, and native lifecycle work can add ticks. Messages/System Prompt may appear in a different observed order; preserve recorded order rather than comparing counts or order to the old implementation. The fixture manifest pins those named changes and unchanged model-facing content.

Migration: native deadlines can record stage attempts and invoke `onAttempt` for each stage; a non-empty environment can add the native signal to provider requests. Run-scoped `session_closed` can follow `integrity.disposition`. Resume reacquires the current provider catalog once before dispatch, including one additional provider `list` call compared with the old cached path. In classic mode after resume, the cached model offer can still name a provider tool that the fresh catalogue omits; dispatch can then report it as unknown.

Migration: a batch with tool-call IDs unsupported by the private binding is refused as a whole before tool dispatch or human questions. Other malformed model batches are refused as a whole only when an actual argument/time ask needs finite checkpoint call IDs. Non-asking batches retain their previous per-call behavior. Saved tool membership discards oldest rows within its finite limits and retains a truncation marker: omitted names never gain authority from a unique current holder. Paused calls carry their own original-party proof, distinct from the current wire. Fresh composition can positively supply the current offered tools. Classic mode has no fresh composition, so a restored cached offer is limited to the membership that can still be resolved; start a new run for a full offer. Oversized declaration labels use distinct tagged digests in the finite carrier without renaming the actual tools or turning labels into authentication. Empty model text is represented by a library-authored assistant notice before corrective user feedback.

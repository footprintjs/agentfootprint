**The LLM ledger's log: entries, a memory store and a MAC-chained file store, inside a closed folder.** `src/llm-ledger/` holds the first part of the LLM ledger: the nine entry shapes and their caps (one frozen table), the record-time builders that keep a read's capped tokens and never its text, the window validator, the session id, the `LedgerStore` port with its closed `LedgerStoreError` codes, an in-memory store and a file store that writes one canonical-JSON line per entry under an HMAC-SHA-256 chain bound to the session, refuses any changed, torn, linked or shared file, and serialises appends across processes with a lock. Nothing imports the folder yet and no package door reaches it; it imports only `footprintjs` and `foottrace`, fenced by the layering table and a new architecture test.

**The evidence gate tells the person's time words from the library's spellings of them.** Under `.time()` beside `.namesAndNumbersFromEvidence()`, an answer about the person's window no longer reads "not traced" for the spellings the library itself produced from a confirmed reading — `08:41` (the end of the said minute "8:40 AM"), `-07:00`, `PDT` for a said `PST`, `15:00Z`, the epoch value the call ran with, a value of the served time line — and those spellings are no longer treated as the person's words either: each judged answer that states one files a `time-derived` row, and the answer's standing folds a new reason, `derived-from-reading` — "not sure", never "known". The parts the person wrote, at the grain they wrote them ("8 AM" is also `8:00` and `08:00`; a confirmed `10/09/26` is `2026-10-09`), and every part of a window they typed in the ask or set in a UI stay theirs. A time no reading produced is still flagged. The spellings have ONE owner, `core/time/forms.ts` · `timeFormsOf` (its `said` and `derived` lists), which also takes over the gate's own clock-spelling table: a person's "8 Am" and a date they chose in a typed ask stay unflagged exactly as before. Values the library converted from a window the person settled in the time ask are no longer exempt as the person's answer — they are derived. Without `.time()` every verdict, event and row is unchanged.

**Save a run's recording in parts, so a reader opens one invocation without the whole run.** `artifacts: { store, recordings: { layout: 'parts' } }` files each completed run as an index (`recording/run-index`), a base part and invocation parts of about 1 MiB (`recording/run-part`); the receipt names the index, and `openSavedRecording` reads only the part it needs. Every part is written first and the index last; each stored part's size and digest are checked against the writer's own, and the index expires no later than its earliest part. If a filing cannot finish (the store refuses a part, keeps different bytes, or its retention evicts one of the recording's own parts), the writer deletes what it wrote, writes no index and reports one `agentfootprint.artifacts.refused`; the answer is unchanged. The default stays `'whole'`, byte for byte as before. The cost, stated on the option: N + 2 awaited store writes per turn instead of one, and a small run takes three artifacts instead of one.

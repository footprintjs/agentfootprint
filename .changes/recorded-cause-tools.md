**Read recorded causes and downstream impact without asking a model to reconstruct the trace.** The trace toolpack adds `attention_list`, `root_cause` and `impact` over the public Foottrace cause reader, with bounded work, scoped proof references and explicit gaps. Hosts can supply an authorized in-memory or stored graph; older snapshot capture remains uncertain. Cause questions can also be asked inside retained tool runs and subflows. Cancellation reaches lazy, nested and delegated reads, and a child's graph is kept separate from its parent's. The dedicated debugger defaults to recorded findings; its explicit hypothesis mode changes the prompt while the tools remain evidence readers. Optional debugger prose still needs host-authored answer validation when semantic delivery guarantees are required.

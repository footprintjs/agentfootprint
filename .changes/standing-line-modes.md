**Say the standing line only when it matters: `.answerLayer({ standingLine: { when } })`.** `standingLine` takes `true` (as before — `'always'`) or `{ when: 'always' | 'unless-consistent' | 'not-sure-or-ask' }`: `'unless-consistent'` leaves the line off a "consistent with the run's record" answer, and `'not-sure-or-ask'` also leaves it off "not assessed" and "known". `ask` is said in every mode. The mode decides only whether the line is appended: the standing still travels as data on `turn_end.answerAssessment` and `agentfootprint.answer.assessed` in every mode, the limits block (`.limitsTravelWithTheAnswer()`) is appended whether or not the line is, and memory keeps exactly the answer that was delivered — with no separator when nothing follows the answer. Silence is never a check: under `'not-sure-or-ask'`, no line means no reason fired, which includes "nothing could be checked"; an app that hides both the line and the data leaves the person unable to tell "checked" from "not assessed". Both option doors refuse a mode that does not exist, and the line in any mode is still refused beside `.answerValidation()` and `.outputSchema()`.

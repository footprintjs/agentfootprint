**A skill can carry a plain name for a person: `defineSkill({ title })`.** "array estate report" for `array-inventory`, at most 60 characters, one line, not the id. It rides `agentfootprint.skill.graph_declared` as `nodes[].title` so a report can name the skill in plain words; the model's request, the activation menu and a graph's drawn `label` are unchanged. A skill without a title records exactly what it did before.

**Refuse construction options that a supplied handle cannot honor.** `RedisStore`, `pgVectorStore`, `BedrockAgentMemory`, `AgentCoreStore`, `s3VectorsStore`, `bedrockEmbedder`, AgentCore memory sessions, OTel strategies and HTTP hosts now reject conflicting public configuration synchronously, before loading an SDK or attaching a listener. S3/GCS artifacts share the same `AdapterConfigurationError` with code `ERR_ADAPTER_CONFIGURATION`, closed `adapter` and `reason` fields. SDK construction failures from the two artifact factories remain sanitized.

Migration: When supplying a prebuilt Redis `client`, move `url` into that client; for pgVector move `connectionString`; for Bedrock/AgentCore/S3 Vectors clients and AgentCore memory sessions move `region`. For OTel, configure the supplied `tracer`'s scope yourself and omit `scopeName`, or omit `tracer` so the adapter requests the declared scope. `agentCoreEvaluationSpans` requires a factory-requested tracer under its fixed evaluation scope: omit `tracer` and configure the installed OTel API, or use `otelObservability` with your own tracer and explicit content-capture policy. A supplied HTTP `server` cannot accompany `port`, `hostname` or `onUnhandled`, including in the Foundry Responses and AgentCore A2A wrappers; configure its address and unmatched-path listeners on that server. This also replaces the existing HTTP configuration error shape. Artifact configuration uses this shared error; configure S3 `region`/`endpoint`/`forcePathStyle` and GCS `projectId` on the supplied client instead. Import the error and its closed types from the affected category door (`artifacts`, `memory`, `providers`, `observe` or `hosting`). Match `code`, `reason` and `adapter` structurally across CJS/ESM boundaries, where `instanceof` identities differ. Explicit empty strings, `false` and zero still count as supplied options; only `undefined` is absent. Operational resource/request settings remain valid with a supplied handle. Internal-only test overrides and SDK-module injection keep their existing semantics.

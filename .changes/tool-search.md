**A tool declares what its search is made of, and the library composes each call's coverage from the arguments the call ran with — `Tool.search`.** A model turns "the tool found nothing" into "it does not exist", and a hand-written `checked` list says the same thing for every call. Now `defineTool({ search })` classifies every input argument by role (`population`, `filter`, `period`, `source`, `cap`, `page`, `inert`), names each default (`whenOmitted`: a value, or `{ any: true }`), each qualifier the tool always applies (`fixed`), each blind spot with the facet it bears on (`gaps`), a server cap (`limits.cap`) and whether a call is complete within its arguments (`complete`). The result says `absent({ what, checked: 'declared' })` (or `coverage(rows, { checked: 'declared' })`), and the dispatch funnel composes the rest from the call: a sent value, a default, a fixed qualifier, the declared or sent source, an identity-filled argument by reference. Every argument none of those covers is a gap; a cap, a page or a `partial` outcome bears on completeness. So composition can only under-claim. The model reads the composed absence (typed items, the gaps, `complete`); the `coverageDeclared` row keeps every value at a library-minted address (`resultId`, never a provider's call id); events carry constants and references, never a composed value. A declaration that arrived over MCP or from a ToolProvider composes rows marked `composed: 'remote'`, which establish nothing. `absent()` and `describedResult()` also take `resolved` (the entity a value resolved to — it binds only the value sent) and `paging` (`{ next: null }` says there is no next page). A malformed declaration, or text that would reach a statement and is multi-line, over 120 characters or instructing, is refused at `defineTool`. A tool with no `search` composes nothing and its run is byte-identical; `absent({ checked: 'declared' })` from such a tool is the call's error. `check:semantics` lists each search's `source.said` words and any `said-overlap` as warnings. An envelope carrying `resolved` or `paging` is refused whole by an older reader, so upgrade readers before tools.

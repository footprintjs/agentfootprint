# Documentation provenance

Only the exact, case-sensitive whole-document header “GENERATED by npm run SCRIPT; do not edit.” is recognised, in an HTML comment at the top or after the title. SCRIPT must exist in package.json and be reached by literal npm-run commands in the docs:generate chain. No command is executed by the predicate. Unknown, orphaned and informal provenance remains authored evidence. The collector lists every excluded path in its report.

Generated sections inside prose, quoted markers, code examples, unknown frontmatter and unclosed markers are not whole-document declarations. Logical/fallback shell commands are not inferred; unproved routes remain authored. The required generated job is the output-regeneration guard.

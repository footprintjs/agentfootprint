# Production source census

The CLI reads the production tsconfig and TypeScript declarations without evaluating application, stage, provider or lazy-resolver code. Collection resolves every production call; any resolved engine builder method must occur in methods.mjs or NOT_A_DECLARATION. The required generated job regenerates the committed map and rejects stale bytes. The full corpus is outside coverage-instrumented Vitest; fixture laws remain there, with their original timeout.

methods.mjs is the single method → kind/id/name/description/target/mount-name table. Positions are zero-based. flowChart/flowChartSelector read name0,id2,description in options3. start/startSelector and regular stages read name0,id2,description3. Streaming uses description4. Branch stages use id0,name1,description3. Parallel-for-each uses name0,id1,description3. Lists report child declarations in argument0 as unresolved aggregate source expressions. Retry loops read id0; their API has no explicit name or description parameter. Eager/lazy mounts use id0,child1,mount-name2; detach mounts read mount-name and description from options2. Other mounts read description from options3. build/end/loopTo/configuration helpers are explicit non-declarations. A new method fails the generator until classified.

syntax.mjs owns source spelling, owner and enclosing-control evidence. bindings.mjs owns package/symbol identity and one alias walker. sourceValues.mjs interprets immutable literal source arguments. collect.mjs joins those jobs; render.mjs escapes Markdown and shows controls for mounts and stages.

Counts are source sites, not runtime instances. Dynamic expressions, spreads, partial binds, mixed signatures, unresolved structural ports and unknown control outcomes stay unresolved. Lists do not imply their runtime expansion. Early returns and caller reachability are not proved. Missing source text does not establish missing inherited built metadata. No historic count, coverage threshold, clock, retry or application-specific heuristic is used.

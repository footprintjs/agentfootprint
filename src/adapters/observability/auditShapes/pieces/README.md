**Lens** — reusable bounds for scripts, coverage, decisions, requests, metadata and tool semantics.

Each file owns one family of whole rules moved from the facade. The shared
constants retain identity for metadata walkers; unknown runtime children remain
markers. Semantics may use coverage rules, with no reverse dependency. No file
imports an event group or the facade.

`bounds.test.ts` checks retained references, fixed error vocabulary, open semantic
records and hostile own keys. The exhaustive audit depth and fates tests cover all
registered rule trees.

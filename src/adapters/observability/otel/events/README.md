**Support** — the existing synchronous event-to-span handlers.

`dispatch.ts` keeps the original cases and close order. `explainability.ts`
records structure and capped standing rows. `late.ts` places evaluations and
checker accounting on the named turn, or makes an explicitly unparented
score. `decisions.ts` bridges flow-recorder evidence only when it can join a
sole active turn and filters the same internal plumbing.

The rule: no handler guesses a sibling run or changes what a content switch
permits. Each owner receives the shared maps, writer functions and stop flag.
The adjacent scenarios check interleaved sessions and stop behavior; the
unchanged public suites exercise the full event vocabulary and output bytes.

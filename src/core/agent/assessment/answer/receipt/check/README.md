**Fold** — compares explicit prose claims about code execution with the receipt for the turn they name.

The checker accepts bounded Markdown prose and previously admitted receipt statuses. It reports verification, contradiction or uncertainty. A confirmed exit can establish execution for a turn. A claim about how a particular value was produced requires its own evidence. The checker has no access to program text or runner output.

An explicit current or previous claim can use its admitted turn receipt. A claim about "that answer" needs the exact previous-answer follow-up. An unresolved reference is recorded as unverified without choosing a turn.

# Result declaration assessment

This sub-flow keeps recorded read limits separate from the bytes a model was
served. `coverage/` owns declaration admission and union; `periods/` owns the
period declaration and joined-witness behavior tests while the existing fold is
wired through the parent. Each has its own README and focused tests.

The common closed reason/witness vocabulary belongs to the parent pure leaf
`../reasonClasses.ts`; neither child stage imports the other. No logic is added
to chart wiring, no result is reconstructed and no persisted holder is added.

**Fold** — result evidence for the answer standing. Each reason family maps committed tool records to the reasons that those records support.

`stage.ts` keeps three parts of the shared fold in order. `readInitialResults` files withholding and legacy period facts before coverage is read. `readResultsCoverage` files library limits and coverage before the fold visits contingent inputs. `readResultEvidence` then reads outcomes, shape, periods and conflicts. The live answer and the saved-record reader use the same steps.

The library limits and window stages read the shared committed result receipts. The window stage counts delivered results removed by an applied window change in the current turn.

Recorded declarations stay separate from the bytes a model was served.
`coverage/` owns declaration admission and union; `periods/` owns period
occurrence lookup and the declaration's joined-witness behavior tests.
The common closed reason/witness vocabulary belongs to the parent pure leaf
`../reasonClasses.ts`; neither child imports the other. No result is
reconstructed and no persisted holder is added.

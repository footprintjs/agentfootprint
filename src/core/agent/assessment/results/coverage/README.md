**Fold** — bounded words from admitted tool coverage and absence declarations.

The projection reads the retained row at the exact occurrence witnessed by the reason. It preserves identical words from distinct registered tools, deduplicates repeat wording from the same tool, and counts statements beyond the shared budget. An oversized advice marker belongs to the advice field itself, so redacting that field hides its count along with its words. A period witness can supply an occurrence through the existing fold.

A visible `why` is read from the same retained item as its subject. Subjects keep their existing selection and spend the quote budget first. The remaining budget admits explanations in order. An earlier warning can be reconstructed with the same subjects and omission count.

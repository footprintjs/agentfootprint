# Period declaration reasons

The existing verdict and time-qualifier tables belong to the common parent pure
leaf `../../reasonClasses.ts`; this folder pins the period behavior. A native declaration
and its matching argument witness retain their meaning when an allowed rule
replaces the result. This does not attest that native bytes were served.

The legacy `nativePeriodServed` proof remains separate: history eviction without
an authoritative settlement cannot establish new delivery evidence.

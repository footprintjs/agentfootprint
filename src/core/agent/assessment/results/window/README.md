**Mixed** — the warning for a delivered result that left the current turn's model context.
At the window write, the library compares the before and after histories for the turn's
settled call occurrences. A strategy's reported eviction list cannot add or omit a witness.
The Fold joins the current turn's unique window removals in `libraryResultLimits` to
delivered call settlements in `stage.ts`. The Lens and the answer account use the same
witness count.

Each witness points to the strategy on a committed receipt, and the warning uses only
its count.

# graph

The graph mount validates one routing declaration and captures its original resolvers and declared map.

These functions receive a typed view of the original builder. They read and write
that receiver directly, preserving method dispatch, registration order and refusal
bytes. The facade retains public signatures, documentation and default evaluation.

# answer

The answer-limit declaration arms exactly one record-composed coverage attachment.
`policies.ts` resolves answer validation, negative claims and retained-source
configuration through their existing native resolvers. The facade retains each
actual field and read/write order; helpers introduce no store or state carrier.
Source option composition preserves the original unmounted options object.

These functions receive a typed view of the original builder. They read and write
that receiver directly, preserving method dispatch, registration order and refusal
bytes. The facade retains public signatures, documentation and default evaluation.

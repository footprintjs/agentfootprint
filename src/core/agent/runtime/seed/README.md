**Walker** — `factory.ts` binds the existing seed stage to its captured native invocation.

The chart retains static declarations and live getters for the catalog that
is completed later in construction. Each native component memoizes its own
seed. Continuation fields are consumed from that component, and clock and
identity accessors never read another selected run. `factory.test.ts` covers
separate fresh turns and an explicit continued conversation through the public runner.

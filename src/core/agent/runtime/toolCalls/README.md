**Walker** — `factory.ts` binds tool dispatch to its captured native component and caller.

Provider offers, served-tool parties, consent, resources, time and retired-run
facts are read from that component. The durable-write accessor still names
the original runner. Static catalog declarations do not become a second run
identity. `factory.test.ts` keeps the existing shared-provider isolation
scenario beside the owner, across classic, dynamic and grouped charts.

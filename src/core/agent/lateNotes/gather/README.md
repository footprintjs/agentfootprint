# Gather late note evidence

Project already served, committed facts into the three available groups, in priority order: declared gaps, tool-result limits, and failed calls. Each needs a readable tool display name. Use the warning's exact settlement admission for coverage and limit facts. A recorded failure uses the settlement's own classification and an exact occurrence match only for its visible name.

The retained WHY remains verbatim for the JSON carrier. Withheld names and words yield no point or private count. Missing coverage, unproved settlement, ambiguous names, and unclassified evidence stay absent. Terminal citation conflicts and unopened tool candidates have no admitted pre-request input in this version.

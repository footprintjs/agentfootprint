# Request-only record notes

The default-off note shares request assembly with the staged-reference tail. The gather stage sees only the record's served values, and the compose stage produces one bounded, attributed JSON note. Keep the prospective note separate from history, the ordinary tail, cache inputs and captured replay prefixes. A selected native adapter decides what it can submit at its final handoff. Each native call records a bounded leaf disposition, and only the selected response can identify the accepted leaf.

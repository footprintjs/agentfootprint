# Tool-call contracts

handlerDeps.ts composes the configuration families consumed by the handler. Native component resources replace the former instance-tier accessor in the P0 major change; catalog preparation serves both normal resume and interrupt replay.

The call cells retain separate initialization phases. Batch and call frames hold ephemeral runtime references for the current invocation, including its original history/result arrays and callbacks. They are never copied into AgentState or checkpoints. Local dispatch completion facts are interpreted only by the native handler.

These files contain types, with no runtime owner, cache, scheduler or execution path. The resource adapter's finite persisted owner carrier remains a separate contract.

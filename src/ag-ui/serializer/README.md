# One-run protocol translation

The `../serializer.ts` facade retains one invocation’s scopes, minter and lexical lifecycle state. This sealed folder owns its unchanged public declarations, pure values, served-event mapping and terminal settlement. Extracted closures receive the same state through per-translation getter/setter ports; they create no second state bank and do not consult a runner. Provider refusals keep distinct closed codes and fixed public sentences, never exception causes, hook messages or raw trace.

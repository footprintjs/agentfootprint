# Mixed — a viewer's display zone
**Walker** (`admission.ts`) validates a new declaration; **Lens**
(`record.ts`) projects recorded metadata for the reader.

The existing time clock owns interpretation. This folder owns only a declared
viewer zone and its presentation projection. Admission accepts one plain own-data
IANA name using the existing zone owner, without reading a getter. Seed files its
purpose-marked value once on the clock row through the existing ledger writer.
A record projection distinguishes absent metadata from present but unreadable
metadata; neither supplies a zone by inference or changes an action's outcome.

The facade ../display.ts exports admission/types and the record projections only.
Formatting remains in ../present.ts and stays off the synchronous runner graph.
All confirmation values, cutoff/end policies and tool arguments remain the
original instants. A new question supplies its own display; a resumed question
reads the original row. No device, process-zone, clock, provider or timer is read.

Native run coverage: test/time/viewer-display-run.test.ts. Pure admission and
projection tests live beside their owners. Implementation is not qualified by the
earlier renderer feasibility probe; exact-head hosted gates and an independent
source read remain required.

Display ownership follows the question's turn. Native pause keeps its clock;
history-only error replay can append a new semantic clock for that same turn.
`displayOfTurn` reads the original declaration without copying it to that new
row or changing that door's existing clock policy. Multiple declarations in an
imported turn are unavailable; a later turn never inherits an earlier display.

# Comparison windows

The comparison binder selects the first declared input form that represents both confirmed endpoints exactly. `arguments.ts` preserves an equivalent proposal, fills or corrects only period arguments, and returns the declaration index for the final check. ISO bounds use precise instants. Epoch and calendar forms use the resolution declared by the form. A relative argument can describe a proposal but cannot carry a confirmed comparison interval to a source.

Before invoking a tool, the dispatcher checks the selected form against the same interval and rejects competing period arguments, including ones introduced by middleware. A shared argument can remain when it belongs to the selected form. Keep returned coverage separate from this request check.

`arguments.test.ts` covers exact conversion, form order, period facts, and alternative keys.

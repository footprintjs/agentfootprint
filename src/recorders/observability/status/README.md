**Lens** (for a human, not the wire) — the chat-bubble surface: what a PERSON watching a run in progress is
shown, one short line at a time.

## What it reads / what it writes
- Reads one event.
- Writes one sentence for a human. Deliberately separate from `../commentary/`
  because the audiences differ: a live bubble and a written narrative are not
  the same reader.

## The one law here
Only what the event carries. An absent field means an absent clause, never a
guess — and never a secret.

# Commentary engine

The parent facade retains the existing exports and override keys. Whole units
now have one owner: types, default templates, routing, variable extraction,
agent naming and non-recursive substitution. `dispositions.ts` exhaustively
classifies every registered kind outside the existing payload-aware routes.
Fixed sentences contain no arbitrary payload or error text; null means an
explicit internal exclusion. Unknown custom events get fixed generic prose.

Existing commentary fixtures pin the old sentences and override keys. Adjacent
tests pin the formerly bare-event dispositions and secret-free fallback.

# Native retained source evidence

Producer declarations describe the final governed model payload. The native
delivery owner alone files receipts and appends their refs to the admitted
continuation index. A receipt shape, artifact kind or caller-supplied reference
does not authorize discovery. Existing artifact storage owns payload retention.

Every find/read requires fresh host admission and current native capabilities.
The host owns current source-scope policy and permitted field projection; an
artifact's same-conversation scope alone proves neither. Current authority is
never reconstructed from old executable arguments, hashes or model prose.

Receipts describe historical reads, including their native limits and period.
They do not refresh a source, certify a later answer, select its subject, or
promote partial coverage. Inner composed calls use no competing artifact store;
their outer governed result may explicitly declare the association.

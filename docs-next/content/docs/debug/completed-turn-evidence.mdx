---
title: Read one completed Agent turn
description: Inspect the recorded causes and coverage of a specific authorized Agent turn.
---

A verified standing host can inspect the evidence of an earlier completed turn even after the same Agent answers another conversation. Set the host's `onCompletedTurn` callback to retain the exact turn you want to inspect. Call `forRequest` with the current request credentials to get an opaque handle. The callback and handle belong in trusted host code.

Use `agent.whatWasNotRead(turn)` for recorded coverage and omissions. For an existing cause-graph node ID, call `agent.why(completed.node(nodeId), turn)` to read the backward evidence. The readers return evidence pointers and gaps, without model calls or raw tool results.

`forRequest` uses the live capture by default. Pass `'saved'` to redeem the exact recording filed for the turn. The host checks the caller again when the handle is used. A paused turn, a lost recording, or access that the host no longer grants cannot supply evidence.

An empty declared-coverage list says the admitted turn recorded no coverage declarations. A gap says the reader could not establish coverage. Missing same-value or skipped-writer evidence produces its own gap.

# Type Alias: ToolArgValidationMode

> **ToolArgValidationMode** = `"enforce"` \| `"warn"` \| `"off"`

Defined in: [src/tools/toolArgsValidation.ts:69](https://github.com/footprintjs/agentfootprint/blob/main/src/tools/toolArgsValidation.ts#L69)

# Published pause writer

The temporary hosted producer installs the exact public 14.1.1 package with a
normally generated strict registry lock, then uses its real Agent API and an
inert provider/tool to write one unchanged native checkpoint. The checkpoint,
manifest and generated lock are retained as evidence. This is not a model call,
application run or release. The producer is removed after its immutable fixture
is captured; the 12.3.0 fixture remains separate and unchanged.

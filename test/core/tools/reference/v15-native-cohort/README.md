`beganAt` and `sawUntil` are log positions, not wall-clock timestamps. The existing
normalizer happens to mask `beganAt` as `<volatile>` because of its name. Raw
snapshot assertions therefore run before projection: `beganAt` must be a
nonnegative integer before its bundle position; a present `sawUntil` must be an
integer later than `beganAt` and no later than that position. Equality with the
bundle position is allowed by Foottrace 2's read-window contract. Required
metadata must be present at every manifest pointer. Business payload fields
with the same names are not interpreted as bundle metadata.
